本项目为 NanoPi R3S / R3S LTS 提供 GitHub Actions 固件构建，支持 ImmortalWrt ImageBuilder、ImmortalWrt 源码和官方 OpenWrt Customer 三条路线；默认根分区为 4096 MiB，Customer 集成 HomeProxy、Nikki / Mihomo、MosDNS、Argon 中文界面及常用网络工具，已移除 PassWall 及其独占组件。工作流支持下载与编译缓存，相关 Actions 使用 Node.js 24 运行时；在 Actions 页面选择工作流并从 main 手动运行，构建产物可从 Artifacts 或 Releases 下载。全新安装默认管理地址为 10.0.0.1，不设置公共默认密码；升级前请备份配置并核验固件校验和，R3S LTS 的 eMMC 启动及硬件功能仍需实机验证。
